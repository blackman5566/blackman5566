## What I Do

我專注在系統設計與資料流。

特別是在：

- 高頻資料更新（real-time）
- 狀態一致性（Single Source of Truth）
- async flow control
- 跨框架架構（SwiftUI / UIKit / Flutter）

讓系統在變動下仍然可預測、可維護。
